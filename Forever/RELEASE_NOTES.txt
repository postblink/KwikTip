KwikTip Forever @VERSION@

Early alpha scope: Hall of Thanes (four encounters), Ragefire Chasm (four), and
Stormwind Stockade (five regular encounters), with optional overviews through Persistent Tip
Window. Normal difficulty 1 only. The default stays quiet between encounters.
This does not detect individual packs, NPCs, rooms or subzones. Ragefire/Stockade
do not assume a next-boss route after kills; reordered fights remain event-driven.
Rare Bruegal Ironknuckle has no verified encounter mapping and no automatic tip.

Client validation: pending. The owner cannot perform live testing before
November 4. Offline Lua/frame tests do not establish game compatibility.
Static IDs target build 1.60.1.70707, interface 16001. Check the current build.
The Infurnus/Magmatus guide association is visibly provisional. Conflicting
Durgen/add kill priorities are omitted. Report exact build, locale, encounter
ID/name and Lua errors; preserve account data and unrelated SavedVariables.

Static MapDifficulty data also contains alternate modes 201/214, which are excluded
from this candidate. The full roadmap remains all Classic dungeon units/wings plus the nine new
Forever dungeons; this alpha does not promise that coverage. No dungeon currently
meets the full client-tested coverage definition. See the packaged README for
manual acceptance and installation details. Disable the addon if it errors.
coverage.json and source-evidence.json list the exact included scope and provenance.

Install only the KwikTip_Forever folder from the ZIP under the Forever client's
Interface/AddOns directory. Keep Retail KwikTip disabled in that client.
